# Central de Relatórios de Erros — QuímicaRush

Este diretório armazena todos os relatórios de bugs, inconsistências de nomenclatura química, problemas de desenho de moléculas ou falhas de interface enviados através da ferramenta de reporte integrada no app.

## Estrutura
- `INDEX.md`: Índice atualizado de todos os relatórios registrados.
- `bug-*.md`: Relatório individual em Markdown detalhado para leitura rápida pelo desenvolvedor / agente de IA.
- `bug-*.json`: Dados brutos completos incluindo telemetria e metadados.
- `screenshots/`: Capturas de tela (prints) enviadas pelos usuários.
